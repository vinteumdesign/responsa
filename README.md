# Banda Responsa — Mídia Kit Interativo

Primeira versão em HTML, CSS e JavaScript puro.

## Como editar

1. Abra `index.html` para alterar textos, seções, links e repertório.
2. Abra `css/style.css` para ajustar cores, espaçamentos e visual.
3. Abra `js/app.js` e troque o número do WhatsApp na variável `WHATSAPP_NUMBER`.

Formato esperado do número:

```js
const WHATSAPP_NUMBER = "5541999999999";
```

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador.

Para publicar:
1. Crie um repositório no GitHub.
2. Envie estes arquivos.
3. Importe o repositório na Vercel.
4. Faça o deploy.
