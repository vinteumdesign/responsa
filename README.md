# Banda Responsa — Mídia Kit Interativo

Versão personalizada com a identidade visual da Banda Responsa.

## Dados aplicados

- Logo oficial: `assets/logo/responsa-logo.png`
- WhatsApp: 41 99827-1848
- Instagram: https://instagram.com/responsabanda
- Paleta baseada nas artes:
  - Azul/noite: `#030326`
  - Verde neon: `#09ff00`
  - Magenta neon: `#ff27d5`
  - Ciano: `#17dff5`
  - Creme/branco sujo: `#fff1da`

## Como editar

- `index.html`: textos, seções, links e repertório.
- `css/style.css`: cores, tipografia, layout e identidade visual.
- `js/app.js`: WhatsApp, filtros e interações.

## Como publicar

1. Criar repositório no GitHub.
2. Enviar os arquivos desta pasta.
3. Importar o repositório na Vercel.
4. Publicar.
